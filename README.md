# YOLO11 Object Detection

โปรเจกต์ Computer Vision สำหรับ Object Detection ด้วย YOLO11

## Environment
- Python 3.12.6
- Ultralytics 8.3.91
- PyTorch 2.6.0 + CUDA 11.8
- YOLO11n
- NVIDIA RTX 2060 6GB
- imgsz 640
- batch 8
- epochs 300

## Dataset
ประมาณ 396 training images และ 1 class

## Project Focus
Model training, dataset preparation, object detection และ evaluation.
